# `@cacao-colab/video` · HyperFrames edutainment studio

Intros MOOC / Microlearning / Masters para Cacao Colab.

## Quick start

```bash
pnpm install
pnpm doctor
pnpm render:dualita
# o
pnpm render:all
```

Outputs aterrizan en `apps/web/public/videos/intros/*.mp4`.

Preview live de una composición:

```bash
npx hyperframes preview compositions/dualita-campus
```

## Style

Lee `frame.md` y `scripts/catalog.json` antes de crear beats nuevos.
