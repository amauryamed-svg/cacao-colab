## Print notes

- Artboard: **180 × 95 mm** + bleed 3 mm (guías).
- Colores spot sugeridos: naranja `#F05A28`, navy `#15243F`, blanco.
- Sustituye el placeholder QR del dorso por un QR real a `https://cacaocolab.org/rd/bars`.
- La mazorca del frente es vector estilizado; para foto real, importa el packshot y enmascara sobre `layer-cacao-pod`.
- URL canónica de producto: **cacaocolab.org/rd/bars** (no Benevolo.co).
