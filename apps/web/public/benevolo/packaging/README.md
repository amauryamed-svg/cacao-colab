## Print notes

- Artboard: **180 × 95 mm** + bleed **3 mm**.
- El SVG de frente **embebe por enlace** el JPG/PNG del diseño Colab. Para enviar a imprenta, entrega **SVG + JPG** juntos (misma carpeta) o rasteriza a PDF/TIFF desde Illustrator/Inkscape.
- QR del dorso sigue siendo placeholder → sustituir por QR a `https://www.cacaocolab.org/benevolo`.
