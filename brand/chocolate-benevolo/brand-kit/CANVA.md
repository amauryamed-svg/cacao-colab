# Canva · 4 minutos · Chocolate Benevolo

Canva no abre un `.fig`. Sube este kit a **Brand Kit** (Canva Pro / Teams) y arma plantillas.

## 1. Colores (1 min)

Brand Kit → Brand colors → Add → pega:

```
#F05A28
#FF6A3D
#15243F
#E8C9A0
#F7F1EE
#140e0a
#C43A18
#FFFFFF
```

Nombres: orange, coral, navy, champagne, cream, cocoa, shadow, white.

## 2. Logos (1 min)

Brand Kit → Logos / Graphics → Upload:

- `logos/cb-monogram-white.svg` (CB sobre cualquier fondo oscuro/naranja)
- `logos/cb-monogram-navy.svg` (CB sobre cream)
- `logos/chocolate-benevolo-lockup-white.svg` **o** `chocolate-benevolo-lockup-live.svg`
- `logos/bars-wordmark-paths.svg` **o** `bars-wordmark-live.svg`
- `logos/chocolate-benevolo-lockup-on-orange.svg` (preview con fondo)

Si Canva aplana el live-text, usa las versiones **paths**. El CB y las letras siguen siendo vectores: cambia color con Recolor.

Respaldo raster: carpeta `png/` (`lockup-on-orange.png`, `cb-on-orange.png`, `bars-on-orange.png`, `kv-*.png`).

## 3. Fuente (1 min)

Brand Kit → Fonts → Upload `type/fonts/BodoniModa-900Italic.ttf` y `BodoniModa-500Italic.ttf` (licencia OFL en la misma carpeta).

Print de **Bars.**: cuando tengas Bodoni Ultra Black Italic licenciada, súbela y úsala solo en el wordmark `Bars.`

Mientras tanto: Bodoni Moda 900 italic, o en el catálogo Canva “Bodoni” Black Italic. No uses Arial Black / Impact.

## 4. Plantillas (1 min)

Create design → Custom size:

| Pieza | px | Archivo a File → Import file |
|-------|----|------------------------------|
| Post | 1080×1080 | `templates/social-post-1080.svg` |
| Story | 1080×1920 | `templates/social-story-1080x1920.svg` |
| Key value | 1080×1080 | `key-values/kv-*-live.svg` |
| Board | 1920×1200 | `key-values/kv-board-1920.svg` |
| Copy Express | 1920×1080 | `copy/bars-copy-board.svg` |

Textos para pegar: `copy/ADOBE-EXPRESS-PASTE.md`

Después: Ungroup (si aparece) → deja bloqueados `logo-cb` y swirls; edita solo `type-*`.

## Qué editar / qué no

| Editar | No tocar |
|--------|----------|
| Copy de anuncio, CTA, foto de producto | Proporción B / enevol / O del lockup |
| Color de fondo entre orange / navy / cocoa | Claims CoEx, stock, “orgánico certificado” |
| Descriptor (80 g, sugar free) | Quitar el punto de **Bars.** |
